## 2. Root cause

The grid's scientific model is defined in **UTC**. The first GAMMA-01 MT5 port reused the R9 core input:

`InpQuoteUtcOffsetMinutes = 0`

and then calculated:

`utc_ms = tick.time_msc - InpQuoteUtcOffsetMinutes * 60000`

This treated the Strategy Tester timestamp as UTC.

That assumption is false for this Coinexx history. MT5 Strategy Tester tick time belongs to the historical quote/server-time domain. The tester cannot reconstruct historical GMT automatically. Coinexx operates a New-York-close style server clock, observed here as UTC+2 in standard time and UTC+3 during US DST.

Consequences of the v1 bug:

1. all STMR fixed-UTC session windows were shifted by the broker offset;
2. session-local lattice reset/anchor times were shifted;
3. Asia/London/overlap/late-NY subphase admission was shifted;
4. the H4 UTC bucket alignment was shifted by +2/+3 hours;
5. therefore H4 environment ownership and downstream sleeve classification changed.

H1/M15/M5 boundaries are less sensitive to a whole-hour offset because their bucket widths divide one hour, but H4 is not. The combination of wrong session ownership + wrong H4 alignment changes the strategy itself.
