# Method scout and implementation decisions

These sources describe methods, not XAUUSD performance. No third-party strategy source or market data was imported. Existing NumPy, Numba and LightGBM packages are used.

| Source inspected | Mechanism adapted | Relevant missing capability | Failure mode / efficient test | Decision |
|---|---|---|---|---|
| https://github.com/bottler/iisignature and its documented iterated-integral API | Degree-two Chen path accumulation, independently written here | Distinguish bid-before-ask, ask-before-bid, spread/path ordering with identical endpoint displacement | Ordered versus reversed fixture, future-prefix invariance, full model versus feature ablation | ADAPT math; no package or code copied; upstream exact revision/maintenance not pinned because no source dependency |
| https://www.pywhy.org/EconML/_autosummary/econml.policy.DRPolicyForest.html (documentation 0.16.0) | Choose action by estimated differential benefit under constraints | Existing global label-risk models do not model action-specific missed-right and avoided-wrong outcomes | Current run CAL loss-constrained selection; frozen VAL and hour/side matched randomized action assignment | ADAPT action-value idea only. Do NOT claim to implement DRPolicyForest or observational treatment-effect identification. All candidate quote paths observable in this hypothetical no-impact study |
| https://www.mql5.com/en/docs/standardlibrary/tradeclasses/ctrade/ctradebuystop | Pending stop trigger above current executable-side reference; explicit server success/result distinction | Earlier no-touch counts were being discussed alongside actual filter performance | Quotes at/after 250ms, strict post-t0 behavior, correct BUY ask/SELL bid entry, side-correct exit, explicit missing exits | ADAPT platform semantics. No real server, volume, book, queue, margin or fills inferred |

Cost: 104 new ordered-path coordinates plus 48 completed-bar transition coordinates; 319 total features including reused native observations. Four action-specific 96-round multiclass LightGBM models; four models without new coordinates for ablation. Capacity is finite and checkpointed. Inference throughput is measured locally after fitting; MT5 budget/parity remains unverified.

Positive-mechanism register: R110's fixed breakout has high hypothetical avoided-wrong capacity but unacceptable missed-correct supply and negative markout. Preserve it as a mechanical action control, with no profit or functional acceptance. R112–R115 delayed guardian rescue is parked. R110-DIST global distribution/calibration is parked. Original accepted F234 is a future composition control whose exact masks are unavailable here; it is not silently replaced. Original fitted teacher is used only for diagnostic overlap and comparison, never as a runtime feature.
