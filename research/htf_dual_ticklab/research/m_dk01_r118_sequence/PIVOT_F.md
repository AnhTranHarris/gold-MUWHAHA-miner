# F401-R118-F — ordered 64-quote sequence encoder with hindsight-phenotype auxiliary loss — PREDECLARED

R118-E continuous future-path quantile/regression transfer is parked. R118-F changes representation from engineered window summaries to the exact ordered native quote-event path.

For every immutable original Dukascopy signal at t0, construct the last 64 source quotes with timestamps strictly <t0. No quote at t0 or later is included. Sequence channels are causal event age, side-relative midpoint path, side-relative tick change, spread ratio, side-relative L1 quoted-size imbalance, relative L1 quoted liquidity, and bid-only/ask-only/joint quote-update marks. L1 size is quoted source liquidity only, never executed volume/L2. Normalize each sequence relative to causally available t0 state; first event with no strictly prior quote receives an explicit zero/abstain sequence.

Neural architecture: temporal convolution encoder with dilated quote-event convolutions; concatenate its latent representation with normalized R118 causal 401D state (quote summaries + matured outcomes + completed M1/M5/M15/H1/H8 geometry/grid/session context); MLP emits (a) original 3-class correct/opposite/neutral logits and (b) an auxiliary historical-teacher-veto phenotype logit. Auxiliary teacher targets are FIT-only supervision and never runtime inputs. This is the explicit hindsight->foresight conversion: the teacher identifies error phenotypes, while the encoder must infer them from source-published past quote sequence.

Train only January chronological FIT with 40s embargo, fixed epochs/checkpoints and no June/July tuning. CAL selects among predeclared runtime risk scores: direct wrong probability, wrong/correct odds, auxiliary teacher-phenotype probability, direct×teacher geometric combination, and max CAL-percentile rank. Correct-loss frontiers remain 0.10/0.25/0.50/1/2/5%. Freeze score/cut on Jan CAL and transfer unchanged to Jan VAL and full Feb/Jun/Jul. Report classwise wrong veto, correct lost, teacher overlap and unique teacher-missed wrong.

If the raw sequence encoder is still low-capacity, it is not to be salvaged with threshold/epoch micro-sweeps. Next distinct work must change the supervisory structure (e.g. contrastive/self-supervised sequence state, mixture-of-experts by latent regime, or exact original teacher leaf/co-occurrence recovery if source weights become available).
