# New Chat — Research Continuation Bootstrap Protocol

Do not invent a new task. First retrieve the user's approved canonical handoff in Drive and verify its newest v1.2 cross-cutting amendment. The canonical snapshot itself is an index, NOT a substitute for the full research original artifacts.

1. Recover the latest immutable source-authorization record; never pull a neighboring GitHub branch or Drive file.
2. Read the full investor mandate and all cumulative anti-drift/whole-system/continuity policies, not an assistant-written recap.
3. Independently read GitHub branch HEAD and parentage; verify against the current handoff commit. No defaulting to `main` or starting a new code branch without maintaining ancestry.
4. Resolve the exact source registry file and SHA-256 and UTC normalization profile; read original research artifacts needed for the task, not their summaries.
5. Read full lineage records, latest frozen experiment plan, complete result receipts/scorecards, original code and relevant checkpoints; validate artifact digests and journal head/count. Distinguish completed, partial, blocked and not-started work.
6. Identify the original in-progress task and the exact next action; continue the task from its last successfully verified checkpoint. No repetitive R9 investigation or new project architecture unless explicitly requested.
7. If an artifact is missing or inconsistent, stop affected scored research, record `BLOCKED_PENDING_RECOVERY`, and request only what is necessary to restore lineage. Preserve known-good branch and old decisions.
8. Before the next scored run, freeze a newly versioned plan referencing its true parents. Use the complete-system comparison gate; retain the negative results and investor constraints.
9. At every major checkpoint, append a hashed journal entry, save exact artifact indices and verified outputs to Drive, and verify GitHub/Drive synchronization. Do not promise background work across chats.

**Machine checks:**

```
python -m htf_ticklab.continuity_guard check-journal governance/CONTINUITY_JOURNAL.json --pinned-head <recorded SHA-256> --pinned-count <recorded count>
python -m htf_ticklab.continuity_guard check-handoff governance/CONTINUITY_CONTRACT.json --observed-head <read-back GitHub SHA> --artifact-root <downloaded original evidence directory>
```

A check without `--artifact-root` validates metadata only and must never be represented as source-byte attestation. Inspect the actual GitHub commit ancestry independently. Example contracts may be templates with placeholders; never treat them as completed real research.
