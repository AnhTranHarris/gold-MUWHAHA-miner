# R9B Gamma Public Breakthrough White Papers

Every formally promoted breakthrough in the R9B Gamma research line receives one dedicated public technical white paper.

## Canonical naming
`R9B_Gamma_<order-number>_<breakthrough-name>`

White-paper filename:
`R9B_Gamma_<order-number>_<breakthrough-name>_WHITEPAPER.md`

Only formally promoted breakthroughs consume a sequence number. Diagnostic research, community reconstructions, failed tests, sub-threshold results and parameter experiments do not.

## Purpose
Each paper is the durable public reconstruction and refinement starting point for that breakthrough. It records discovery lineage, mechanism, causal/data contract, Jan–Jul evidence, system value, integration role, robustness, failure modes, implementation mapping and future refinement state.

## Promotion invariant
A breakthrough is not considered documentation-complete until:
1. its canonical R9B_Gamma ID is assigned;
2. its public white paper exists;
3. the paper references the exact promoted source/result identities;
4. its Jan–Jul aggregate and monthly validation are recorded;
5. its incremental value versus the prior best integrated baseline is recorded;
6. the refinement-starting-point section is complete.

Use `WHITEPAPER_TEMPLATE.md` as the required structure.
