# Checkpoint 08 — Post-Catastrophe KEEP / FLIP

This cumulative checkpoint makes the post-stop state explicit.

After a catastrophic losing stop:
1. the 10-second same-direction failed-thesis memory remains active;
2. for a wider configurable window, a new HFT auction must have strong causal action evidence;
3. a strong opposite action is labeled FLIP;
4. a strong renewed same-direction action is labeled KEEP;
5. weak follow-up auctions abstain.

This is deliberately not an automatic reversal rule. Immediate reversal was rejected in the research.

Two portfolio mechanics are also corrected here:
- one existing opposing sleeve is now actually permitted when the configured maximum is one;
- an R9 event blocked by portfolio heat/capacity is consumed rather than becoming a stale delayed entry.
