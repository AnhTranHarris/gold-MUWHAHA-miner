# Checkpoint 02 — P3 / P4 / P6 Specialists

This cumulative checkpoint adds executable state specialists to the R9-derived R10 chassis.

- **P3**: delayed failed-ignition exit after the trade has had time to declare itself. Immediate blind reversal remains rejected.
- **P4**: low/normal-volatility + relatively inefficient travel routes the R9 auction event to a FADE.
- **P6**: high-volatility or highly efficient travel routes the event to CONTINUE.

The project sources preserve the P4/P6 state definitions and performance but not every original fitted threshold. Therefore the numeric P4/P6 cutoffs are exposed as **reconstructed tester defaults**. They must be re-certified in MT5 and may not be described as recovered original coefficients.

The R9 minute event and ten-second causal state remain the parent event chassis.
