## Install locally on Windows (full EA compilation, no incremental handoff required)

1. Download/clone the specified Stage 6 branch; keep the original R9 EA separate. Use a fresh work directory. Download the following **existing unmodified ZIP files** from MT5_EXPAND into an assets folder, with filenames unchanged. Do not extract or rename them for the installer:
   - [Stage 5 base](https://drive.google.com/file/d/1_7NlBjXJhaMinQ8KgBk9Egf95avIeqW1/view) `R9_HYBRIDGATE_V1_STAGE5_PORTABLE_ENGINEERING_20261125.zip`
   - [Stage 5 D–I](https://drive.google.com/file/d/1s_FJev13ZBiBiTDVVhb77VMFZqy0HMS2/view) `R9_HYBRIDGATE_V1_STAGE5_D_I_ENGINEERING_QC_20261125.zip`
2. From the repository root run (Python 3.11+ standard library only; no third-party packages):
   `py -3 engineering/hybridgate_v1/prepare_install.py --assets C:\HybridGate\assets --dest C:\HybridGate\staged`
   Destination must not exist. Expected 240 manifest entries (62 source copies, 88 models, 89 fixtures, one license). The installer checks archive hashes, every source and model/fixture SHA-256, local includes and readback. `INSTALL_MANIFEST.json` is generated. Python is used only for installation, not by the EA.
3. In MT5 choose File > Open Data Folder. Copy the staged `MQL5` tree into the terminal data folder's `MQL5`, preserving relative paths and avoiding overwriting unrelated files. Model assets go under `MQL5/Files/HG5QC`, includes under `MQL5/Include/HybridGateV1`, QC scripts under `MQL5/Scripts/HybridGateQC`. The EA contains all 88 tester_file declarations; verify local tester-agent sandbox separately. Do not bypass a missing/hash failure. This installer does not modify a terminal automatically.
4. **Stage 7A — compile only.** Open `MQL5/Experts/HybridGateV1/GoldMuwahahaMiner_HybridGateV1.mq5` in MetaEditor; press F7. Send complete compiler output, MetaEditor build and MT5 terminal build. Zero errors/warnings is the target, not a claim already met. Leave `InpRequestDemoExecution=false`, `InpRequestTesterExecution=false`, and `InpTesterRescueExisting=false` during compiler and observation QC. Demo request remains refused; the tester opt-in is not authorized for native use until the release gate is cleared. Do not enable or alter the execution gate.
5. Once full source compiles, run the three preserved offline QC scripts (`HG5InferenceQC.mq5`, `HG5CoreQC.mq5`, `HG5ReleaseQC.mq5`) and provide all logs. This is behavioral QC, not an incremental EA development handoff. Attach EA for observation only after verifying exact symbol/account grid, source history and clock mapping. Use a new run ID only for intentional independent observation. A run ID is not a safe way to bypass ambiguous real-order intent. No actual demo/live orders or actual MT5 trade backtest results in this build. Tester opt-in remains unverified natively.
