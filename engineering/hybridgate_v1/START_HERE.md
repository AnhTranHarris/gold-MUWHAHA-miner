## Install locally on Windows (full EA compilation, no incremental handoff required)

1. Download/clone the specified Stage 6 branch; keep the original R9 EA separate. Use a fresh work directory. Download the following **existing unmodified ZIP files** from MT5_EXPAND into an assets folder, with filenames unchanged. Do not extract or rename them for the installer:
   - [Stage 5 base](https://drive.google.com/file/d/1_7NlBjXJhaMinQ8KgBk9Egf95avIeqW1/view) `R9_HYBRIDGATE_V1_STAGE5_PORTABLE_ENGINEERING_20261125.zip`
   - [Stage 5 D–I](https://drive.google.com/file/d/1s_FJev13ZBiBiTDVVhb77VMFZqy0HMS2/view) `R9_HYBRIDGATE_V1_STAGE5_D_I_ENGINEERING_QC_20261125.zip`
2. From the repository root run (Python 3.11+ standard library only; no third-party packages):
   `py -3 engineering/hybridgate_v1/prepare_install.py --assets C:\HybridGate\assets --dest C:\HybridGate\staged`
   Destination must not exist. Expected 237 manifest entries (59 source copies, 88 models, 89 fixtures, one license). The installer checks archive hashes, every source and model/fixture SHA-256, local includes and readback. `INSTALL_MANIFEST.json` is generated. Python is used only for installation, not by the EA.
3. In MT5 choose File > Open Data Folder. Copy the staged `MQL5` tree into the terminal data folder's `MQL5`, preserving relative paths and avoiding overwriting unrelated files. Model assets go under `MQL5/Files/HG5QC`, includes under `MQL5/Include/HybridGateV1`, QC scripts under `MQL5/Scripts/HybridGateQC`. For Strategy Tester agents, verify the model sandbox separately: assets are not automatically guaranteed to exist in agents' Files directory. Do not bypass a missing/hash failure. This installer does not modify a terminal automatically.
4. Open `MQL5/Experts/HybridGateV1/GoldMuwahahaMiner_HybridGateV1.mq5` in MetaEditor; press F7. Send complete compiler output, MetaEditor build and MT5 terminal build. Zero errors/warnings is the target, not a claim already met. Leave `InpRequestDemoExecution=false`. The build itself refuses true. Do not enable or alter the execution gate.
5. Once full source compiles, run the three preserved offline QC scripts (`HG5InferenceQC.mq5`, `HG5CoreQC.mq5`, `HG5ReleaseQC.mq5`) and provide all logs. This is behavioral QC, not an incremental EA development handoff. Attach EA for observation only after verifying exact symbol/account grid, source history and clock mapping. Use a new run ID only for intentional independent observation. A run ID is not a safe way to bypass ambiguous real-order intent. No actual demo/live orders or actual MT5 trade backtest results in this build.

Reproduce from a fresh installation on Linux with GCC, OpenSSL development headers and Python: `python engineering/hybridgate_v1/test_host.py --install /path/to/staged --build /path/to/new-host-run`. This does not test MetaEditor. The model bank and original 67,754-vector tests are preserved. Native acceptance tests are in `ACCEPTANCE_TESTS.csv`; do not change NOT_RUN without a native receipt.

The observation candidate uses an exact-cents XAUUSD grid and USD account assumptions; incompatible symbols are rejected, not coerced. The actual account is distinct from the 12 historical simulated configurations. Current broker adapter assumes one owned exposure, hedging, FOK, and an explicitly verified clock. These are unapproved production integration restrictions until platform tests. It cannot certify all future inputs or latency. Actual fill delays, broker margin/stopout/costs, partial fills, authoritative ledger/journal and watchdog arming, clock/DST/live calendar, terminal file durability and performance still require native integration/operational testing. MT4 is not included. No independent forward results, deployable profits or account survivability guarantee. Retain evidence of failures and fix implementations only.
